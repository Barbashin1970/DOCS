# Документация · РАГРАФ и LEYKA

> Публичный хаб документации двух продуктов **Центра ИИ НГУ**: платформы регламентов **РАГРАФ**
> и системы управления проектами **LEYKA**. Здесь — руководства, примеры и материалы; сам код
> продуктов лежит в отдельных (приватных) репозиториях.

---

## Что внутри

| Раздел | О чём | Перейти |
|---|---|---|
| 📐 **РАГРАФ** | ИИ-модератор регламентов: замкнутый контур «датчик → регламент → задача → человек», визуальный конструктор Flow, объяснимость по построению | [`RAGRAF_DOCS/`](RAGRAF_DOCS) |
| 🗂 **LEYKA** | Система управления проектами с мессенджер-Лентой и ИИ-модератором; цифровой диалоговый ассистент (ЦДА) | [`LEYKA_DOCS/`](LEYKA_DOCS) |

**Как они работают вместе:** РАГРАФ замечает событие, сверяет его с регламентом и ставит задачу
в LEYKA; LEYKA через webhook возвращает факт выполнения обратно в РАГРАФ — контур замыкается.

## Курс по конструктору РАГРАФ

Программа повышения квалификации ЦИИ НГУ (ДПО). На курсе **всё покажем, научим и дадим скачать ПО
локально**: вы получаете экземпляр **РАГРАФ Lite** (Docker + инсталляторы для macOS и Windows),
**лицензию Lite на льготных условиях** (для слушателей НГУ её фактически покрывает обучение),
рабочие регламенты на своих данных и сопровождение после курса.
**Запись и вопросы:** banksnab@gmail.com.

## Статус и лицензирование (кратко)

- РАГРАФ и LEYKA — **проприетарные продукты ЦИИ НГУ**, не open source.
- Построены на **открытых компонентах** (MIT / Apache 2.0 / BSD) — лицензии на компоненты покупать
  не нужно; зависимости от иностранных проприетарных вендоров/облаков нет.
- **Модель монетизации — сервисная:** лицензия РАГРАФ Lite ≈ 0 (покрывается обучением); деньги —
  с обучения, внедрения и ежегодного сопровождения.
- **Σ СИГМА** — отдельный продукт городского масштаба со своей моделью лицензирования.
- Создано в рамках НИОКТР, тема **СИГМА** (договор гранта № 70-2023-001318 от 27.12.2023;
  грантодатель — Минэкономразвития РФ).
