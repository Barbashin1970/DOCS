# Примеры регламентов — визуальные карточки

Эта страница — витрина регламентов платформы РАГРАФ в формате Mermaid-диаграмм.
Каждая карточка показывает граф регламента (визуальный DSL Flow), как он выглядит 
в редакторе Flow Editor, плюс ссылки на исходные `*.flow.json`, `*.data.ttl` и SHACL-формы.

GitHub рендерит Mermaid-блоки нативно — кликайте по любому регламенту, чтобы посмотреть.

Всего регламентов: **46**, сгруппированы по 11 доменам (по одной подпапке на домен).
